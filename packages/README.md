# Pacotes partilhados

Definições partilhadas entre aplicações (tipos de dados, validações, textos). Sem regras financeiras duplicadas.

| Pacote | Conteúdo |
| --- | --- |
| `design-system` | Identidade visual: tokens, componentes base, logótipo. Ver `design-system/README.md` |
| `dominio` | Regras financeiras puras: dinheiro em decimal exato, taxas, cotações. Sem base de dados nem rede |

Ver `docs/04-estrutura-do-repositorio.md`.
