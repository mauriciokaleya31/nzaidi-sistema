| [0003](0003-base-de-dados-relacional-e-ledger.md) | Base de dados relacional e contabilidade de dupla entrada | Proposto |
| [0004](0004-adaptadores-para-integracoes.md) | Adaptadores substituíveis para integrações externas | Proposto |

Modelo: Contexto, Decisão, Alternativas, Consequências, Estado.
