**Plano de Negócio (PDF): fora do repositório, de propósito.** Contém o NIF, o registo comercial, a estrutura societária e dados da empresa que não devem estar num repositório de código. Fica guardado pela gestão. O que é relevante para quem programa está resumido em `../01-visao-geral-e-objetivos.md`, `../10-regras-financeiras.md` e `../16-registo-de-decisoes.md`.

Este PDF é uma fotografia de 25/10/2026. Se algo mudar, a decisão nova entra em `../15-decisoes-pendentes.md` e `../16-registo-de-decisoes.md`, e o PDF deve ser regenerado.

Nota: o PDF usa a palavra **Acordado** onde estes documentos técnicos usam **Confirmado**. Significam o mesmo.
